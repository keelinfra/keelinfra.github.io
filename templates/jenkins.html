Install

One script, plain sh, any old Unix

1

It asks your controller

install.sh asks the controller which agent it ships and downloads the agent8 release for that Jenkins version, built for the host's Java.

2

It checks before it swaps

Downloads are checked against sha256sums.txt and test-started on the local Java. The old jar is kept, and --restore puts it back.

3

You restart as usual

Same java -jar command, same service script. Offline hosts use --from DIR; fleets use the Ansible playbook.

Questions teams ask first

Is this an official Jenkins project?

No. Agent8 is independent and not endorsed or supported by the Jenkins project. Report problems on its GitHub issues, not the Jenkins tracker.

Why not run the build in a container?

That works for many RHEL 6 builds. It can't cover builds that must run natively on AIX, Solaris or HP-UX hardware.

Which launch methods work?

Inbound agents, started with java -jar agent.jar. The SSH Build Agents launcher copies its own jar to the host and isn't supported yet.

What is the license?

MIT. The jars include JvmDowngrader classes under LGPL-2.1.
