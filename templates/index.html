Agent8 for Jenkins

Available · MIT

Jenkins requires Java 21 on every agent, and RHEL 6 or AIX 7.1 build hosts can't run it. Agent8 is a Jenkins agent built for Java 8: the controller runs Java 21 or 25, the old host keeps its Java 8 and stays an ordinary node. Tested in CI on Linux, including RHEL/CentOS 6; AIX, Solaris and HP-UX are experimental.

Don't take our word for it

Take the Keycloak distribution: every claim about it is a public CI run, a published probe log, or a drill you can run against your own cluster. The full ledger →

$ ./verify                     # health of every component
$ ./verify --drill failover    # switch the PostgreSQL leader over, write through it
$ ./verify --drill restore     # restore the latest backup to a scratch directory
$ ./verify --drill session     # rolling-restart every node; logins must survive

CI runs a clean install plus the session drill on every commit, and the upgrade matrix re-proves every supported upgrade path nightly.
